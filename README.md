# 个人 Skill 仓库

目前只有一个 Skill：[中文自然写作](.github/skills/zh-natural-writing/SKILL.md)。它用来写中文消息、技术说明和工作汇报，尽量让人一遍看懂，同时保留原文里的条件和不确定性。[改写示例](.github/skills/zh-natural-writing/references/examples.md)里也列了哪些句子不用改。

**在自己的 Copilot 里用：** 把 `.github/skills/zh-natural-writing` 整个目录复制到个人目录 `~/.copilot/skills/` 下。想让 Copilot 每次回复前都加载它，再把[这段指令](.github/copilot-instructions.md)追加到 `~/.copilot/copilot-instructions.md`，保留原有内容，然后新开会话。只想在一个项目里使用，就把 Skill 和指令放在那个仓库的 `.github/` 下。

本仓库收录的是修订版，保留了[早期上游项目](https://github.com/Onenightcarnival/zh-natural-writing)的 [MIT 版权声明](.github/skills/zh-natural-writing/LICENSE)。
